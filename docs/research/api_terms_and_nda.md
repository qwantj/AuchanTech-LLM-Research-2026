# Технические требования: Structured Output, лицензии и режим NDA

## 1. Совместимость со строгим выводом (Test IT 18 столбцов)

Прототип `testgen` выгружает тест-кейсы в корпоративный шаблон Test IT (строго 18 столбцов `A–R`, 0 склеенных ячеек, защита от формул Excel). Для исключения синтаксических сбоев необходима гарантированная генерация валидного JSON по схеме Pydantic v2:

| Модель | Механизм строгого вывода | Комментарий для `testgen` |
|---|---|---|
| **DeepSeek V4.1 Flash / V4 Pro** | OpenAI-совместимый `response_format={"type": "json_schema"}` и `tools` | Полностью совместим с существующим клиентом `Instructor` / OpenAI SDK без переписывания схем. |
| **Qwen4-Max / Qwen Flash** | OpenAI-совместимые эндпоинты Alibaba Cloud Model Studio (`json_schema`) | Поддерживает строгие схемы и мультимодальный разбор таблиц/макетов экранов. |
| **Gemini 4 Carbon / Hydrogen** | `response_format` с `mime_type="application/json"` и JSON Schema | Требует учёта актуального SDK `google-genai` (Interactions API 2026 г.). |
| **GPT-6.2 Sol / Astra** | `strict: true` JSON Schema | Эталонная поддержка строгих схем со 100% соблюдением типов. |
| **Qwen3.8-27B / Qwen3.6-35B-A3B (локально)** | Grammar-constrained decoding в `vLLM` / `SGLang` (`guided_json`) | Гарантирует 100% валидный JSON даже при локальном запуске; устраняет проблему нестабильности маленькой `Gemma 4B`. |

## 2. Лицензионная чистота для коммерческого контура

- **`DeepSeek V4.1 Flash` и `DeepSeek V4 Pro`:** открытая лицензия **MIT** — разрешено любое коммерческое использование, дообучение и локальное развёртывание без ограничений по выручке.
- **`Qwen/Qwen3.8-27B`:** лицензия **Apache 2.0** — полностью свободное корпоративное развёртывание внутри инфраструктуры ООО «АшанТех».
- **`GLM-5.3`:** открытые веса под лицензией GLM-5.3 (требует проверки условий при крупномасштабном коммерческом тиражировании).

## 3. Архитектура соблюдения NDA (информационная безопасность)

1. **Режим закрытого контура (целевой для реальных ТЗ АшанТех):** Docker-контейнер с прототипом работает полностью без доступа в интернет; запросы направляются на локальный сервер инференса (`Qwen3.8-27B` или `Qwen3.6-35B-A3B`). Ни один байт документации ТЗ не покидает периметр компании.
2. **Облачный режим (только с допуска ИБ и на обезличенных/синтетических данных):** при использовании внешних API обязательно соблюдаются политика Zero Data Retention (ZDR), запрет на обучение провайдера на пользовательских данных и предварительная фильтрация секретов.
